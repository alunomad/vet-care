# VetCare - Hospital Veterinário e Centro Diagnóstico 🐾

O **VetCare** é um projeto de desenvolvimento front-end que simula a página institucional de uma clínica veterinária e centro diagnóstico. O projeto foi desenvolvido com foco em acessibilidade, semântica, responsividade e organização modular do código.

---

## 📌 Visão Geral e Objetivo

O objetivo deste projeto é aplicar os conceitos de arquitetura CSS, HTML5 semântico e metodologia BEM no desenvolvimento de uma aplicação web responsiva. A página apresenta a estrutura do hospital, corpo clínico, especialidades, setor de FAQ interativo e formas diretas de contato.

---

## 🚀 Tecnologias e Conceitos Aplicados

- **HTML5 Semântico:** Utilização de tags estruturais (`<main>`, `<section>`, `<article>`, `<header>`, `<footer>`, `<details>`, `<summary>`) para garantir acessibilidade e SEO.
- **CSS3 Modular:** Separação de responsabilidades em múltiplos arquivos externos (`reset.css`, `design-system.css`, `global.css`, etc.).
- **Metodologia BEM (Block Element Modifier):** Padronização da nomenclatura de classes e seletores no CSS.
- **Design System com Variáveis CSS (`:root`):** Padronização de paleta de cores, tipografia e sombras.
- **Escala de Fontes em REM:** Configuração de unidade relativa baseada no elemento raiz para tipografia e espaçamentos.
- **Flexbox & Layout Responsivo:** Uso de porcentagens (`%`), unidades de área de visualização (`vh` e `vw`) e *media queries* para adaptação em smartphones, tablets e desktops.
- **Google Fonts:** Importação da família tipográfica *Poppins* (pesos 400, 500, 600 e 700).
